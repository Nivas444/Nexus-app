## 6. PO Filter and Material Filter

Implement the filters using the actual PO quantity and net material quantity fields from the existing database schema.

### PO Filter

Calculate:

`PO Difference = JMS Qty − PO Qty`

In the relevant main line-item table, rows with a PO Difference less than zero must be highlighted in red.

In the dedicated **PO Filter** tab, show only rows whose PO Difference is greater than zero, as requested for this tab.

### Material Filter

Calculate:

`Material Difference = JMS Qty − Net Material Qty`

In the relevant main line-item table, rows with a Material Difference less than zero must be highlighted in red.

In the dedicated **Material Filter** tab, show only rows whose Material Difference is greater than zero, as requested for this tab.

### Important distinction

The main table's negative-difference highlighting and the dedicated filter tabs' positive-difference selection are separate requirements. Do not accidentally use one sign condition for both views.

- Main table: show the appropriate negative-difference warning in red.
- PO Filter tab: show only positive PO Difference rows.
- Material Filter tab: show only positive Material Difference rows.

Apply these rules only to `JMS to be validate` rows. Other task categories must not inherit these filters.

If the existing UI or schema makes either quantity or sign interpretation ambiguous, inspect the current business logic and report the exact conflict before changing the calculation.

Ensure all filter calculations use the latest persisted JMS Qty.
