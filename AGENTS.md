### Customization Workflow
- Understand the requested change and inspect only the relevant code.
- If essential requirements are unclear, ask concise clarification questions before implementation.
- Do not produce lengthy implementation plans. Summarize the intended change in 1–3 bullets at most.
- Once requirements are clear, implement directly without repeated approval requests.
- For clear, low-risk requests, proceed without unnecessary questions.
- Modify only relevant files and preserve existing functionality.
- Run targeted verification, fix implementation-related errors, and provide a concise result summary.
- Never commit or push unless explicitly instructed.
